# ЧИСТО — Premium Car Wash

Концепт премиального сайта автомойки в Москве. Проект создан как работа для портфолио: выразительный BMW M4 hero-блок, тарифы, карточки выполненных работ, адаптивная навигация и интерактивная форма выбора даты и времени.

 https://chisto-premium-moscow.laks1919627.chatgpt.site/
 
## Возможности

- адаптивный лендинг на русском языке;
- три тарифа: 1 500 ₽, 3 000 ₽ и 5 000 ₽;
- карточки работ с эффектом blur/reveal;
- ручной ввод марки автомобиля и года выпуска;
- интерактивный календарь на 14 дней;
- демонстрационные свободные и занятые слоты;
- страницы услуг и контактов.

## Портфолио-режим

Это безопасная демонстрационная версия. Она не содержит Telegram-бота, API-маршрутов, базы данных, токенов, ключей и конфигурации рабочего хостинга. Форма записи работает только как UI-демонстрация и никуда не отправляет введённые данные.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
pnpm install
pnpm dev
```

Для проверки production-сборки:

```bash
pnpm build
```

## Стек

React 19, Next.js 16, TypeScript, Vinext, Vite и CSS.
